Good questions

Everything you're wondering.

Is this a macOS clone?
No. MacPiOS is an open-source maker dashboard inspired by polished desktop interfaces — the familiar dock, windows and menu bar — but it's its own thing, wrapping real apps you control. It's not a reskin of macOS and it doesn't try to be.
Does it run on Windows too?
Yes. Anything that can run a small Node backend and serve a browser works — Raspberry Pi, Windows, Linux or a home server. It's one interface for Pi, Windows and mobile.
Do I need a monitor on the Pi?
No. It's served over your network (Tailscale or a Cloudflare Tunnel) and you open it from any browser — phone, tablet, laptop or kiosk. The Pi stays headless.
Is the terminal real?
Yes — xterm.js wired to node-pty over a WebSocket. It's a genuine shell on your machine, not a simulation. The same goes for Files, Services, Docker and the remote browser.
Is it secure?
All API and terminal access sits behind a bearer token, and you can sign in with a WebAuthn passkey (Face/Touch ID). Service and Docker controls are allowlisted server-side. Serve it over your private tailnet for an extra layer.
What does it cost?
Nothing. It's free and open source. Clone the repo, drop the file into your server's static directory, and you're running.
How do I add my own app?
Add one object to the APPS registry with a mount(body) function that renders into the window, then add its id to the dock order. That's the entire contract — no build step.
